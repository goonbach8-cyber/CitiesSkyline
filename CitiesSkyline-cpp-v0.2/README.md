# City Lab C++ v0.2

Browser-faehiger 3D-City-Builder-Prototyp in C++17 mit raylib und WebAssembly.

## Enthalten
- echte 3D-Kamera mit WASD, Zoom und Rotation
- Strassen per Drag-and-drop
- Wohn-, Gewerbe- und Industriezonen per Flaechenmarkierung
- Gebaeude entstehen automatisch an Strassen
- Gebaeude koennen wachsen
- Einwohner, Jobs, Geld und Nachfrage
- Bulldozer
- GitHub Actions Deployment auf GitHub Pages

## Steuerung
- `1`: Strasse
- `2`: Wohnen
- `3`: Gewerbe
- `4`: Industrie
- `5` oder `B`: Bulldozer
- `WASD`: Kamera bewegen
- rechte Maustaste ziehen: Kamera drehen
- Mausrad: Zoom
- `SPACE`: Pause

## Deployment
GitHub Pages muss unter **Settings -> Pages -> Source** auf **GitHub Actions** stehen.
