# CitiesSkyline – Browser Prototype

Erste kleine Testversion eines eigenen City-Builders.

## Enthalten
- Rasterbasierte Stadtkarte
- Straßen bauen
- Wohn-, Gewerbe- und Industriegebäude
- Gebäude benötigen eine angrenzende Straße
- Geld und Baukosten
- Einwohnerwachstum
- Einnahmen durch Einwohner und Betriebe
- Pause und 1x/2x/4x Geschwindigkeit
- Abriss und Reset

## Lokal starten
`index.html` im Browser öffnen.

## GitHub Pages
Für eine öffentliche Browser-Version kann in den Repository-Einstellungen unter **Pages** die Branch `main` als Quelle ausgewählt werden.
