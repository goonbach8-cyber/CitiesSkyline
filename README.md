# Cities Prototype v0.2

Browser-Prototyp eines City-Builders.

## Neu in v0.2
- große Karte
- Kamera mit WASD / Mausrad / Panning
- Straßen per Ziehen
- Wohn-, Gewerbe- und Industriezonen aufmalen
- Gebäude wachsen automatisch an Straßen
- Einwohner- und Jobsimulation
- Nachfrageanzeigen
- Speichern/Laden über LocalStorage

Zum Testen `index.html` öffnen oder über GitHub Pages veröffentlichen.
