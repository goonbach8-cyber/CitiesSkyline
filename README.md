# City Lab C++ v0.3

Browserfaehiger C++/raylib City-Builder-Prototyp.

## Neu in v0.3
- 80x80 Karte statt 64x64
- prozedurales Terrain mit Huegeln
- Fluss/Lake-Wasserbereiche, auf denen nicht gebaut werden kann
- 8 Wohn-, 6 Gewerbe- und 6 Industrievarianten
- Haeuser mit Fenstern, Tueren, Daechern und Kaminen
- Shops mit Schaufenstern und Schildern
- Buerogebaeude mit mehreren Stockwerken
- Industriehallen, Tanks und Schornsteine
- Gebaeude-Level veraendern die Hoehe/Details
- vorhandenes Zoning-, Nachfrage-, Geld- und Straßensystem bleibt erhalten

## Steuerung
- WASD: Kamera bewegen
- Rechte Maustaste ziehen: Kamera drehen
- Mausrad: Zoom
- 1: Strasse
- 2: Wohnen
- 3: Gewerbe
- 4: Industrie
- 5/B: Bulldozer
- SPACE: Pause

GitHub Actions kompiliert das Projekt mit Emscripten nach WebAssembly und deployed es auf GitHub Pages.
